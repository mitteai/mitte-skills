by field, every error and diagnostic code, the limits, the engine CLI, the service configuration, and the registry
as published. Written against the code of engine 0.1.48 / service `975dfdf`; where the spec disagrees, the page says
what the code does under a `> **Spec gap:**` note. Generated sections sit between `<!-- gen:<name>:start/end -->`
markers and are regenerated by the scripts listed at the bottom.

## Examples

`examples/` holds the verified examples: `*.motion.json` documents (`rexx-engine check` passes with no error),
`inputs/motion.<tool>.<name>.json` tool inputs (validated against the published schemas), `registry.json` (the
registry dump the schema pages are generated from). `python3 SKILLS/tools/examples/check-examples.py --engine
<rexx-engine> [--ffmpeg …]` checks them all.

## Generators (`scripts/`)

| Script | Regenerates | Needs |
|---|---|---|
| `skills-tools-schemas.py --service-bin <rexx>` (or `--from-json examples/registry.json`) | `90-schemas.md`, `91…95-schema-*.md`, `examples/registry.json` | a built service binary (boots it with the stub engine) |
