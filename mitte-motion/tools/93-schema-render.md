Render a motion document to video (MP4, MOV/ProRes with alpha, WebM with alpha) or an image sequence, in one or several aspect-ratio variants. Deterministic: the same document renders the same bytes.

| Field | Value |
|---|---|
| `category` | `motion` |
| `cost` | 4 |
| `timeout_ms` | 1200000 (20 min) |
| `sandbox` | `local` |
| `sync` | false (omitted) |
| `resource_limits` | 4 CPU / 6144 MiB / 256 pids |
| `output_asset_type` | `video` |

Use cases:

- Deliver a motion graphics video (a motion film, title sequence, explainer, lyric video or social ad) from its motion document.
- Render the final video after a clean motion_check and a look at motion_frames.
- Render every aspect-ratio variant the user needs (default, vertical, square) in one call.
- Export a ProRes or WebM clip with alpha for compositing elsewhere, or a poster frame alongside the video.

Instructions (verbatim, what the assistant reads):

```text
Required: doc or doc_url (exactly one).
Optional: variants (ids rendered in one job, each its own file) or variant; data; output (format, codec and alpha as the schema lists them for this box; quality draft|standard|high|master; alpha true, false or "stacked"; fps; scale 0.25–2; range [in, out]; audio; hdr hlg|pq for 10-bit Rec.2020 HDR video, HEVC by default in mp4/mov and AV1 in webm, values above 1 kept with 1.0 = 203 cd/m², PQ with mastering display and measured MaxCLL/MaxFALL, HLG for Instagram; encoder cpu|nvenc, the GPU encoder for h264, hevc and av1 on a GPU box, refused elsewhere; output.toneMap and output.hdrPeak come from the document); poster (true or a time: also return a PNG).
Output: one file per variant (labelled) plus the poster; data with per-variant duration_s, frames, fps, size, bytes, codec, ms_per_frame, wall_ms, cache_hit, warnings; doc_hash, engine versions, total duration_s.
Errors: the document has errors (nothing rendered, no charge); a format this box cannot write, a codec the container cannot hold, alpha with a format that cannot carry it, HDR on a format or codec that cannot carry it, an explicit odd output.size for a chroma-subsampled format, or encoder nvenc with a codec, alpha plane or PQ it cannot write or on a box without it (diagnostics output.format_unavailable, output.codec_container, output.alpha_unsupported, output.hdr_unsupported, output.size_odd, output.encoder_unsupported); more variants, frames, or render time than allowed.
```
