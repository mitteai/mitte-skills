# Registry entry: `motion.check` (generated)

What `GET /v1/registry/motion.check` publishes, generated by `scripts/skills-tools-schemas.py` from a booted service; the hand-written reference is the tool's own page in this folder. Do not edit between the markers.

Validate a motion document and report errors, design warnings, a timing sheet, and a render-time estimate. Does not render.

| Field | Value |
|---|---|
| `category` | `motion` |
| `cost` | 1 |
| `timeout_ms` | 60000 (1 min) |
| `sandbox` | `local` |
| `sync` | true |
| `resource_limits` | 1 CPU / 1024 MiB / 256 pids |
| `output_asset_type` | none (data only) |

Use cases:

- Check the document of a motion graphics piece (a motion film, title sequence, explainer or social ad) before frames and render.
- Check a motion document before rendering.
- Get the timing sheet to review pacing.
- See the canonical (expanded) form of a document.

Instructions (verbatim, what the assistant reads):

```text
Required: doc (the motion document, a JSON object with "motion": 1) or doc_url (https URL or library:<namespace>/<path>@<version> URI of a .motion.json asset) — exactly one.
Optional: variant; data (merged over the document's data); lint ({platform: none|broadcast|youtube|shorts|reels|tiktok|linkedin|x, disable: [codes]}); canonical (true or "url"; large, debugging only); sims ("url": upload each comp's physics bake for locking).
Output: data.ok, diagnostics (severity, code, message, path = JSON pointer into your document, hint, optional fix), stats (comps, layers, keys, expressions, duration, fps, frames, size, variants, fonts, library; assets: one row per referenced asset with id, type, source, bytes and layers = how many layers use it), estimate (msPerFrame p50/p95/max, renderSeconds, costliest layers; backend = the renderer the job takes, "cpu" or "gpu", with cpuMs and gpuMs = the per-frame estimate on each and gpuComplete = whether the GPU renders the whole document itself; encoder = the document's output.encoder, "cpu" or "nvenc", which only a GPU box writes), timing (text table: per layer, visible span, seconds fully on screen, entrance, exit, notes; beat markers as rows), sims (with sims: "url": per comp {comp, hash, url, sha256}; declare the url as an asset of type "sim" with that sha256 and set the comp's physics.lock {asset, hash} to keep the take).
Errors: neither or both of doc and doc_url; invalid JSON; doc over 2 MB; an asset src that is neither an https URL nor a library:<namespace>/<path>@<version> URI of an asset the library ships (asset.bad_url). Problems inside the document are diagnostics with ok=false, not errors.
Notes: always check before frames or render; fix every error, then weigh warnings. skill:rexx/tools/30-diagnostics.md explains any code.
Related: motion_frames, motion_render.
```
