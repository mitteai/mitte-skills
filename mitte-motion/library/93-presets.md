# Catalogue: every library preset

Generated by `scripts/skills-library-index.py` from `library/mitte/presets/*.library.json`. Use one as `"preset": "mitte/<name>@1"` on a timeline entry; `props` fills the params, and `dur`/`ease` on the entry override the preset's own. The tweens are shown as written in the library (no `target`: the entry's target is implied; `at` is relative to the preset's start). How to write your own is in `02-presets.md`.

## Pack `editorial` (1.0.0, draft)

Long, soft entrances for serif layouts: generous distances, a sine or soft-expo curve, a touch of blur, nothing that bounces. Durations follow the theme's `dur.xl` and `dur.l`, so they stretch further under `mitte/editorial@1` than under `mitte/clean@1`.

Tags: preset, enter, editorial, serif. File: `library/mitte/presets/editorial.library.json`.

### `mitte/editorial.rise@1`

Rises a long way with a soft landing: y from +distance, opacity 0, an 8 px blur that clears over the first two thirds. Use on `title/lines` with a 0.12–0.2 s stagger for pull quotes and chapter titles.

`dur`: `"$theme.motion.dur.xl"` · `ease`: `[0.16, 1, 0.3, 1]`

| Param | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `distance` | number | `60` | 10–300 | Rise distance in pixels. |
| `blur` | number | `8` | 0–30 | Starting blur in pixels; 0 for small text. |

```json
[
  {
    "from": {
      "y": "+=$props.distance",
      "opacity": 0
    }
  },
  {
    "from": {
      "blur": "$props.blur"
    },
    "dur": "$theme.motion.dur.l",
    "ease": "sine.out",
    "at": 0
  }
]
```

### `mitte/editorial.fade@1`

A slow fade with an almost invisible settle in scale (102 → 100). For body text, captions, bylines, images: anything that should simply be there when the eye arrives.

`dur`: `"$theme.motion.dur.l"` · `ease`: `"sine.inOut"`

| Param | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `scale` | number | `102` | 100–110 | Starting scale in percent; 100 disables the settle. |

```json
[
  {
    "from": {
      "opacity": 0,
      "scale": "$props.scale"
    }
  }
]
```

## Pack `kinetic` (1.0.0, draft)

Bold per-word type entrances with overshoot and squash. Use on `title/words` with a stagger of 0.08–0.16 s, or on a single hero word. One slam per piece; the rest of the copy should enter quietly.

Tags: preset, enter, kinetic, type. File: `library/mitte/presets/kinetic.library.json`. Note: `kinetic.flip` is a 2D flip (scaleY through zero) because `flipIn` needs 3D layers or `threeDPerChar` (P2). The 3D version lands as `kinetic.flip` 2.0 with a `threeD` param.

### `mitte/kinetic.slam@1`

The word arrives from far too big and lands hard: scale 260 → 100 with a quartic ease-out, opacity in over the first third, a 10 px blur that clears as it lands. Pair with a `shake` on a rig null for the impact.

`dur`: `"$theme.motion.dur.s"` · `ease`: `"power4.out"`

| Param | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `from` | number | `260` | 120–600 | Starting scale in percent. |
| `blur` | number | `10` | 0–40 | Motion-feel blur at the start, pixels. |

```json
[
  {
    "from": {
      "scale": "$props.from",
      "blur": "$props.blur"
    }
  },
  {
    "from": {
      "opacity": 0
    },
    "dur": "$theme.motion.dur.xs",
    "ease": "power2.out",
    "at": 0
  }
]
```

### `mitte/kinetic.stomp@1`

Drops in from above and stomps: y from −distance with an accelerating ease, then a one-beat squash (wider, shorter) that recovers with overshoot. Reads as weight; use for the last word of a line.

`dur`: `"$theme.motion.dur.s"` · `ease`: `"power3.in"`

| Param | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `distance` | number | `160` | 40–600 | How far above its rest position the word starts, pixels. |
| `squash` | number | `14` | 0–40 | Squash amount in percent: scaleX grows and scaleY shrinks by this much on landing. |

```json
[
  {
    "from": {
      "y": "-=$props.distance",
      "opacity": 0
    }
  },
  {
    "to": {
      "scaleX": "+=$props.squash",
      "scaleY": "-=$props.squash"
    },
    "dur": 0.06,
    "ease": "power1.out",
    "at": ">"
  },
  {
    "to": {
      "scaleX": 100,
      "scaleY": 100
    },
    "dur": "$theme.motion.dur.s",
    "ease": "$theme.ease.emphasis",
    "at": ">"
  }
]
```

### `mitte/kinetic.flip@1`

A 2D card flip on the horizontal axis: scaleY from 0 with a small drop, overshooting on arrival. Works on words and on whole lines; keep the stagger short (0.06 s) so the flip reads as one gesture.

`dur`: `"$theme.motion.dur.base"` · `ease`: `"back.out(1.8)"`

| Param | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `drop` | number | `24` | 0–120 | Small downward travel as the word opens, pixels. |

```json
[
  {
    "from": {
      "scaleY": 0,
      "y": "-=$props.drop"
    }
  },
  {
    "from": {
      "opacity": 0
    },
    "dur": "$theme.motion.dur.xs",
    "ease": "linear",
    "at": 0
  }
]
```

### `mitte/kinetic.stretch@1`

Letters start spread and stretched wide, then snap together with an elastic settle: tracking from wide to normal, scaleX from 150, opacity in. Good for a single kicker or brand word; avoid on long copy.

`dur`: `"$theme.motion.dur.l"` · `ease`: `"elastic.out(1, 0.55)"`

| Param | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `tracking` | number | `300` | 0–1000 | Starting tracking in thousandths of an em. |
| `stretch` | number | `150` | 100–300 | Starting horizontal scale in percent. |

```json
[
  {
    "from": {
      "scaleX": "$props.stretch",
      "tracking": "$props.tracking"
    }
  },
  {
    "from": {
      "opacity": 0
    },
    "dur": "$theme.motion.dur.s",
    "ease": "power2.out",
    "at": 0
  }
]
```

## Pack `ui` (1.0.0, draft)

Short, Material-timed UI motion for product demos: dialogs, menus, toasts, tooltips, cards. Durations are fixed in the 150–300 ms band on purpose (they do not follow the theme's `dur` tokens, because UI should feel like UI under every brand); eases are the Material 3 emphasized and standard curves.

Tags: preset, enter, ui, material. File: `library/mitte/presets/ui.library.json`.

### `mitte/ui.pop@1`

A dialog or menu appears: scale from 92 % and opacity 0 over 250 ms on the Material emphasized-decelerate curve. Use for modals, popovers, cards that appear on a click.

`dur`: `0.25` · `ease`: `[0.05, 0.7, 0.1, 1]`

| Param | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `from` | number | `92` | 50–100 | Starting scale in percent (smaller reads as more distance). |

```json
[
  {
    "from": {
      "scale": "$props.from"
    }
  },
  {
    "from": {
      "opacity": 0
    },
    "dur": 0.15,
    "ease": "linear",
    "at": 0
  }
]
```

### `mitte/ui.slide@1`

A sheet, toast, or panel slides in a short way with a fade, 300 ms on the Material standard curve. `offset` is where it starts relative to its rest position: `[0, 32]` rises from below, `[-48, 0]` comes from the left.

`dur`: `0.3` · `ease`: `[0.2, 0, 0, 1]`

| Param | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `offset` | list | `[0, 32]` | 2–2 items | Start offset `[dx, dy]` in pixels relative to the rest position. |
| `offset[]` | number | — | — |  |

```json
[
  {
    "from": {
      "position": "+=$props.offset"
    }
  },
  {
    "from": {
      "opacity": 0
    },
    "dur": 0.2,
    "ease": "linear",
    "at": 0
  }
]
```

Note: A `vector` param type does not exist (spec 12 §12.3.2), so the offset is a two-item number list; an enum `dir` cannot pick an axis because the template grammar has no conditionals.

### `mitte/ui.fade@1`

Plain opacity in over 200 ms, linear-ish (Material standard accelerate reversed). For tooltips, hover states, secondary labels; anything that should not draw attention.

`dur`: `0.2` · `ease`: `[0.3, 0, 0.8, 0.15]`

No params.

```json
[
  {
    "from": {
      "opacity": 0
    }
  }
]
```
