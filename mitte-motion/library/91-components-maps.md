Notes from the library file:

- The shaft is a smooth `polyline` (Catmull-Rom) through tail, a bent control point and the tip, drawn with `drawOn`. The arrowhead gets its angle from `autoOrient: "path"`: it rides the last tenth of the curve and stops on the tip pointing along it, which also gives the draw-on its motion (a static `rotation` from `atan2` of the tangent, which the template grammar has had since engine 0.1.33, would work for a still head). The label is set in Caveat (the hand-drawn look is the point, so the font is fixed). `lint.motion_blur_off_fast_motion` on the arrowhead is waived: it moves for three frames while fading in.

Notes from the library file:

- The moving marker is the classic trim trick: a second copy of the route path with a wide round-capped stroke and a trim window 0.3 % long whose `start` and `end` travel together with the same ease and duration as the draw-on, so the dot rides the tip. `from`/`to` are two-number lists because no vector/point param type exists (spec 12 §12.3.2), raised as a signal. The shade and marker stroke widths use `{{$props.width * 2.2}}` arithmetic at component level, which spec 12 §12.4 only states for repeat templates (assumption, raised as a signal).
