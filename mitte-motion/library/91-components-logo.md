### `mitte/logo.reveal.draw@1`

Strokes of an SVG logo draw on along their paths over `draw` seconds, the filled logo fades in as the last strokes land (with a 97 → 100 settle), holds `hold` seconds, then draws off and fades. Use a line-art or stroked SVG.

Notes from the library file:

- Two layers import the same SVG: `outline` is trimmed (`drawOn` adds a `trim` to the root contents, so every path draws together), `fill` fades in. There is no authored way to add a stroke to `fromSvg` contents or to hide their fills, so the SVG must carry the strokes itself; `stylize.outline` would be a raster fallback and does not draw on. Raised as a spec signal.
