# mitte-skills

Skills for working with mitte from an AI assistant. One folder per skill, each with a `SKILL.md` at its top.

| Folder | What it covers |
|---|---|
| [mitte-motion](mitte-motion/SKILL.md) | Motion graphics: writing motion documents and calling the `motion.*` tools (check, frames, render, convert, track). |

## Sources

`mitte-motion` is a copy of `SKILLS/` in [mitteai/rexx](https://github.com/mitteai/rexx) at commit `c1dad91`. The rexx repository is the source: edit the pages there, then copy them here again.
